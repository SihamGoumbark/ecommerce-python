
# E-Shop - Site Web E-Commerce (Python / Django)

Application web e-commerce développée dans le cadre du module **Python** (Licence Universitaire Spécialisée ILSI - ENSAK).

## Technologies utilisées
- **Back-end :** Python, Django
- **Front-end :** HTML5, CSS3, Bootstrap 5, Font Awesome, GSAP
- **Base de données :** SQLite

## Fonctionnalités principales
- **Catalogue et recherche :** Consultation des produits, filtrage par catégorie (Femmes, Hommes, Enfants) et barre de recherche dynamique.
- **Panier & Commande :** Ajout/suppression d'articles, calcul automatique du total et validation de commande (paiement à la livraison).
- **Authentification & Profil :** Inscription, connexion, déconnexion et gestion des informations du profil utilisateur.
- **Espace personnel :** Liste de souhaits (Wishlist) et suivi de l'historique personnel des commandes.
- **Administration :** Gestion complète des produits, catégories, commandes et utilisateurs via l'interface Django Admin.

## Installation et exécution
1. Installer les dépendances :
   ```bash
   pip install django pillow

```

2. Lancer le serveur de développement :
```bash
cd siham_goumbark_ecommerce
python manage.py runserver 9000

```


3. Ouvrir le navigateur sur : `http://127.0.0.1:9000/`
